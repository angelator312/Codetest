# This is an example for the `codetest graderDev`
The tutorial is for this example folder(for your own needs replace `guess.cpp` with your file)
1. you need to run `codetest graderDev CPP=guess.cpp`
  - This will mean that your grader is `guessGrader.cpp` and in the grader you include  `guess.cpp`
  - When you attempt to submit the code you will submit `guess.cpp`
